# denishen.co.za

Personal website of Denishen Perumal CA(SA), served by GitHub Pages at https://denishen.co.za.

- `index.html` – the whole site (about, skills, career, qualifications, journal).
- `Denishen_Perumal_CV.pdf` – downloadable CV linked from the site.
- `CNAME` – tells GitHub Pages to serve the site on denishen.co.za.

Journal posts live in the `POSTS` list near the bottom of `index.html`. Posts with `draft: true` stay hidden while `SHOW_DRAFTS` is `false`.
